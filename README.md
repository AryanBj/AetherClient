# Aether Native macOS Client

A fast, lightweight, and native macOS graphical user interface (GUI) for the [Aether](https://github.com/CluvexStudio/Aether) censorship circumvention tool. Developed using Apple's SwiftUI for maximum performance and minimal battery/RAM usage.

**Developer:** Aryan ([@AryanBj](https://github.com/AryanBj))
**Telegram:** [@aryanbj](https://t.me/aryanbj) | **X (Twitter):** [@aryan_bj](https://x.com/aryan_bj)

## Features
- **Native macOS UI:** Built strictly with Swift/SwiftUI (No Electron/Tauri overhead).
- **Full Protocol Support:** MASQUE (HTTP/3 & HTTP/2), Wireguard, and Gool.
- **Advanced Configuration:** Routing rules, Noise obfuscation, Upstream proxy routing.
- **Built-in Core:** The Aether core engine is bundled directly within the app.

## How to Use
1. Go to the [Releases](../../releases) page.
2. Download the latest `aether-aryanbj.zip`.
3. Extract and move the `.app` file to your Applications folder.

# کلاینت نیتیو مک برای Aether

این پروژه یک رابط گرافیکی (GUI) بومی، سریع و بسیار سبک برای ابزار ضدسانسور [Aether](https://github.com/CluvexStudio/Aether) است. این کلاینت کاملا با زبان Swift اپل نوشته شده و برخلاف ابزارهای مبتنی بر وب، هیچ فشار اضافه‌ای به رم و باتری مک‌بوک شما وارد نمی‌کند.

## قابلیت‌ها
- پشتیبانی کامل از پروتکل‌های MASQUE و Wireguard و Gool
- تنظیمات پیشرفته شامل مبهم‌سازی (Noise)، پروکسی بالادستی و مسیریابی
- تعبیه شدن هسته اصلی درون خود اپلیکیشن بدون نیاز به ترمینال
